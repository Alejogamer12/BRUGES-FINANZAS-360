BRUGES FINANZAS 360 — INFORME DE VERIFICACIÓN
Fecha: 8 de octubre de 2026
Versión del código: 1.3.0+4

RESUMEN
La compilación Windows 1.3.0 terminó correctamente. El instalador se compiló con Inno Setup 6.7.3, se instaló de forma silenciosa en una carpeta temporal y la aplicación abrió manteniéndose activa. Android 1.3.0 no se pudo compilar en esta sesión: una prueba mínima de Java confirma que Selector.open() falla antes de Flutter/Gradle con “Unable to establish loopback connection”. El APK/AAB anteriores corresponden a v1.2.0 y se retiraron de la carpeta de entrega para no confundirlos con la versión actual.

VERIFICACIONES DE CÓDIGO
- `flutter analyze --no-pub`: aprobado, sin problemas.
- `flutter test --no-pub`: aprobado, 30 pruebas.
- `npm test` en `backend`: aprobado, 4 pruebas.
- `npm run typecheck` en `backend`: aprobado.
- Android: compilación release intentada con JDK Temurin 21 y con el JDK incluido en Android Studio; ambas fallaron al inicializar el canal local NIO. Se reprodujo el mismo error con un programa Java mínimo en ambos JDK. El intento con un selector alternativo no fue compatible y se descartó.
- Windows: `flutter build windows --release`: aprobado.
- Inno Setup 6.7.3 compiló el instalador: aprobado.
- Instalación de humo en una carpeta temporal: el log indicó “Installation process succeeded”; se generaron los accesos de Inicio y Escritorio. La aplicación ejecutable inició y permaneció activa durante la comprobación.

COMPATIBILIDAD Y ARTEFACTOS
- La configuración Android del proyecto declara minSdk 24 (Android 7.0), targetSdk 36, paquete `com.bruges.finanzas360`; el APK universal anterior contenía arm64-v8a, armeabi-v7a y x86_64.
- No se generó ni probó un APK 1.3.0. No se instaló esta versión en emuladores o teléfono físico; no se comprobó un POCO X7 Pro 5G ni otros fabricantes con los cambios actuales.
- El instalador Windows actual es x64 y tiene 10.974.340 bytes. SHA-256: `AAA6CE61DD04045AEDF843E4DC6CDA60205A992E8BF013FD76ED332FE636948E`.
- El instalador pasa la prueba de instalación y apertura en este equipo. No está firmado con certificado Authenticode (Windows lo muestra como `NotSigned`); Windows SmartScreen puede mostrar advertencias.
- El AAB/APK archivados en `work/previous-v1.2.0/` son del release beta v1.2.0, versionCode 3; no son los artefactos de este código 1.3.0+4.
- No hay clave privada de firma Android de distribución configurada. Las versiones previas usan firma debug: válida para pruebas, pero no para publicación en Google Play ni para futuras actualizaciones con una clave distinta.

FUNCIONES Y SEGURIDAD
- Se implementó historial local con agrupación por día/semana/mes/año, búsqueda adicional por monto/fecha, edición auditada de movimientos manuales, bloqueo de edición de filas de origen externo y migración del ledger a versión 3 con historial de cambios.
- Las pruebas cubren filtros, agrupación, persistencia, migración, recuperación de respaldo, duplicados locales, CSV/JSON, enlaces de WhatsApp y flujos de interfaz indicados por cada test. No sustituyen pruebas de usuario real.
- No existe despliegue Convex configurado ni URL de producción/JWT; autenticación, sincronización entre dispositivos, administración en servidor, correo de recuperación y datos persistentes en la nube no están disponibles ni comprobados. La app guarda movimientos localmente.
- Las observaciones de avisos Android son sugerencias pendientes de revisión; no confirman pagos ni consultan directamente sistemas bancarios. No se probaron avisos reales de bancos.
- No se comprobaron biometría, push remoto, actualización automática, uso sin conexión y posterior sincronización en dispositivos reales, ni acceso a información cruzada de varias cuentas.
- No se proporcionaron credenciales/certificados de producción. La beta no debe presentarse como servicio bancario conectado ni como producto listo para guardar datos financieros sensibles de terceros.

PUBLICACIÓN Y DESCARGAS
- La automatización `.github/workflows/build-installers.yml` prepara APK+AAB en Linux y el instalador en Windows, y puede publicar assets al crear un tag `v*`.
- No se publicó esta versión: no se creó un release v1.3.0 porque falta el APK/AAB 1.3.0 compilado/verificado. La página pública puede seguir mostrando el release beta previo.
- Instalador Windows local: `BRUGES-FINANZAS-360-INSTALADORES/BRUGES-FINANZAS-360-Setup.exe`.
- Copia del instalador en la carpeta de entregables: `outputs/BRUGES-FINANZAS-360-Setup.exe`.
- La carpeta de instaladores no contiene ahora un APK/AAB 1.3.0. Los APK/AAB beta v1.2.0 se conservaron bajo `work/previous-v1.2.0/` para evitar etiquetarlos incorrectamente.

VEREDICTO
Entrega parcial. El instalador Windows 1.3.0 se compiló, instaló y abrió en este equipo. Android 1.3.0 permanece pendiente por el error de loopback de Java que reproduce el entorno. No se afirma que Android, la nube o integraciones bancarias hayan superado pruebas con esta versión. La automatización CI está preparada para generar los archivos Android en un runner de GitHub; sus resultados no se consideran aprobados hasta que el workflow se ejecute y sus assets se inspeccionen.
