# BRUGES FINANZAS 360

BRUGES FINANZAS 360 es una aplicación que estoy desarrollando para ayudar a las personas a llevar un mejor control de su dinero desde un celular Android o un computador con Windows.

La idea es que sea fácil de usar y que permita organizar los ingresos, gastos y movimientos de dinero en un solo lugar, para saber cuánto dinero entra, cuánto sale y en qué se está gastando.
